## 陳正未來三至五年的連續性

允許服裝材質與價格、髮型整潔程度、鬍渣與儀容、表情姿勢及合理的自然成熟改變。由落魄軍人轉為有產商人，不構成更換五官的理由。

不得無理由改變臉型骨相、眼型與眼距、鼻子及下顎比例、頭部比例、顴骨臉頰結構與身形；不得突然老化或年輕十幾歲、忽胖忽瘦。耳側既有傷痕應維持正確解剖側別、位置與形態，不得換邊或無故增減。遮擋、背光或解析度不足應標記為無法確認，不直接判定傷痕消失；不可混淆畫面左右與人物自身左右。

## 新圖審查流程

1. 先依 Markdown 引用、正式資產及實際檔案查找參考圖與候選圖；缺圖應列出確切檔名，不能假裝已比較。
2. 實際檢視原圖，再比較陳正的臉型下顎、眼型眼距眉骨、鼻樑鼻翼嘴部比例、顴骨臉頰、髮際線頭部比例、膚色年齡感、耳側傷痕、身形氣質。阿順另行比較年輕感、機靈神態與五官輪廓，不只檢查主角。
3. 先列前兩章共同特徵及內部矛盾，再逐張比較候選圖。區分透視、表情、光線造成的合理變化與骨相比例改變；不能單憑像素相似度或臉部辨識分數判斷。
4. 看房圖須核對陳正、阿順與趙二房東查看破屋的情節；長衫可以更換，臉不能隨之更換。吃麵圖須核對兩人在街頭吃麵、陳正留意對街柳掌櫃被催問金雞納霜，並比較側臉、四分之三側臉及兩張候選圖彼此的一致性。
5. 場景對照核准正文與 1925 年上海背景。涉及不確定的歷史物件、招牌或服裝斷言，另查可靠來源；未核實即標記待查。
6. 報告逐張列出陳正一致性、阿順一致性、具體差異及保留／局部重繪／重生建議。不可檢視圖片時停止視覺結論，明示限制。
7. 作者確認後才可整合；審查本身不授權生圖、修改圖片、指定正式人物標準或發布。

修正指令應點名參考圖、人物位置與需要對齊的部位，例如：「保留候選圖的場景構圖及長衫，依附上的已採用參考圖對齊陳正的臉部輪廓、眼型眼距、鼻樑鼻翼及下顎比例；耳側傷痕維持參考圖經確認的解剖側別與位置。不得因穿著體面就改成另一張更成熟或更俊美的臉。」具體差異必須來自實際審查，不預填未觀察到的五官特徵。
