# 共創記憶｜《台南少年追風記》

> 用途：跨回合接續創作時先讀這份記憶。這是創作共識與故事事實，不等於可擅自改寫的正式小說原稿。
> 更新：2026-10-28｜EP.05〈夢醒時分〉以作者認可的「看得下去」精簡版為基礎，追加四項局部回收；本包為**提交／上架候選稿**，尚需 Codex 整合測試，不得宣稱已上線。

## 一、作品定位

- 作品：《台南少年追風記》，收錄於《臆想書房》。台灣大學生青春群像；台南的街道、機車、海風、音樂與相處細節是底色。
- 敘事以 **柏翰第一人稱**為主，口氣自然、貼近台灣大學生。可以有「幹／靠北」等口頭語，但不是每段都要靠粗口製造活潑。
- 作品是小說，不是逐字日記；可以虛構事件，但需維持人物關係、內部邏輯與情緒真實。
- 章節通常圍繞「一段經歷、一首歌、一個地方」，但**不是固定公式**；時間順序可交錯，不強制鎖死年份以容納不同時期的歌曲。

## 二、核心人物

- **柏翰**：第一人稱主角，對音樂、台南與朋友的生活片刻敏感；嘴上愛鬧，偶爾冒出令人意外的真心話。互動共創時，重大選擇、核心台詞與情緒轉折由作者決定。
- **嘉豪**：柏翰的重要朋友、室友；需打工，重視班表和經濟現實；外表嘴賤卻很投入朋友的事。不要只寫成搞笑工具人。
- **翔宇**：三人中的另一位朋友、自稱狗頭軍師，有時過度自信（例如搶票程式），常創造意外笑點；也有共同參與及在乎彼此的一面。避免不間斷插話。
- 三人相處有台式互損與幹話，也需要有**不說話、同看、同唱、同做一件事**的時刻。

## 三、章節與呼應

- **EP.01〈夏夜晚風〉**：柏翰失戀後與嘉豪到漁光島聽伍佰〈夏夜晚風〉；**一副 AirPods 各戴一邊**，是往後重要的回憶錨點。
- **EP.02〈擁抱〉**：時間可早於 EP.01，柏翰在吉他社認識並追求國貿系學姊，邀請她吃永豆，取得聯絡方式。
- **EP.03〈安平之光〉**：柏翰、嘉豪在安平港的夕陽與遊船，聽〈安平之光〉，感情由日常共遊自然累積。
- **EP.04〈30CM〉**：柏翰、嘉豪、翔宇深夜逛國華街／海安路／神農街、談未來與十年後相聚，伍佰以外的音樂也可成為回憶載體。
- **EP.05〈夢醒時分〉**：三人期末考前搶到伍佰高雄巨蛋演唱會三張連號票；翔宇的搶票程式失靈、嘉豪手動成功，翔宇欠鹽酥雞。嘉豪為了請假對老闆說母親生病，知道不妥並打算之後補班。台南→高雄；舞台上有電風扇、同步發光棒與波浪舞。〈夏夜晚風〉呼應 EP.01，嘉豪會唱中段獨白並曾舉手機錄影；〈夢醒時分〉由伍佰起「你說」帶出全場接唱與吐槽；安可的〈樹枝孤鳥〉回收火車上柏翰推薦的歌，小說化最後一首是〈你是我的花朵〉。散場時柏翰想起背包裡原封未動的期末講義，然後跳接台南鹽酥雞。嘉豪回放影片卻幾乎只有自己的破音歌聲，被命名《嘉豪 & China Blue 高雄巨蛋演唱會》。三人約定「只要伍佰還唱，我們三個都還在，就去」，最後以「明天誰有早八」回到現實。
- EP.05 的演出流程與安可歌曲**可為小說化編排**，不主張與任何一場真實演唱會逐秒一致；引用現場梗需分清可考證的事實與作者改寫。

## 四、第五章帶來的重要創作偏好

- 作者對此前的冗長完整版明確表示**「太多贅字，看不下去」**；對「在精簡版底稿上適度恢復演唱會體感，刪除重複笑點、快速切過場」的修訂版則表示**「這版可以欸，看得下去」**。
- 有效的敘事：進場前用少數對話完成角色與障礙；唱歌時讓音樂主導，不再一人講一句；只在必要處用感官細節；一句真心話點到即止。
- 有效的喜劇：**嘉豪在車上問為何買票唱給伍佰聽 → 現場被全場接唱震撼 → 手機回放只有自己的歌聲**，有鋪墊、有回收、只留最有力的笑點。
- 有效的情感：〈夏夜晚風〉對照 EP.01 一人一耳機，不必用長篇心理解釋；最後的約定和碰杯簡單帶出友情與時間感。
- **請勿因作者說「沉浸感不足」就機械地加長景物／心理／對話**；沉浸感來自精準節奏、具體動作和現場聲音，不等於增加字數。

## 五、更新記憶時的原則

- 新角色、人物關係、伏筆、已確定的故事發展可以補充；若新稿和本檔衝突，優先採作者**最新明確確認的正文**，更新本檔而非自行修改正文。
- 把「已發生的正文事實」「正在腦力激盪的想法」「現實考證」分開標記，不要把試寫、梗或歷史資料誤寫成既定情節。
- 上架狀態、章節文本與 Git 同步狀態都要根據實際檔案或作者確認，不得從討論過程猜定。
